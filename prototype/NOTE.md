# Superseded

This is the original single-file build of the portfolio — plain HTML, CSS and
JavaScript, produced straight from the Claude Design document before the site
was ported to the Next.js + Express workspace that surrounds this folder.

Nothing here runs as part of the site and nothing imports from it. It is kept
because it is where the design actually came from: the wave field's constants,
the glass treatments and the type scale were all read out of these files during
the port, and the comments in `web/src` refer back to "the design" meaning this.

Open `index.html` directly in a browser if you want to see it.
